# ✍️ حزمة OCR الخط اليدوي (عربي + إنجليزي + ألماني) — من نسخ احتياطية HF Bucket إلى نموذج مدرَّب

تدريب نموذج OCR لكلمات الخط اليدوي بثلاث لغات (العربية والإنجليزية والألمانية)،
ببدء من محتويات الـ bucket `DrAbdulmalek/github-repo-backups` (المجلد
`2026-10-14`)، وتحويل صفحات الخط اليدوي إلى **قصاصات كلمات**، وتخزينها في
**SQLite**، ثم تدريب نموذج بمعمارية **TrOCR** على Colab T4.

```
1_download_bucket.py  →  2_inspect_backups.py  →  3_labeling_app.py
   (تنزيل الـ bucket)      (استخراج + تجهيز صفحات)     (قص ووسم الكلمات)
                                                            │
                                              3b_review_app.py
                                          (مراجعة الوسوم الآلية: قبول/تصحيح/تجاهل)
                                                            │
                                              7_box_editor_server.py
                                    (تعديل مربعات الكلمات على الصفحة: سحب الحواف/تقسيم/دمج)
                                                            │
        6_predict.py  ←  5_train_trocr_colab.py  ←  4_export_dataset.py
          (تجربة)            (تدريب TrOCR على T4)      (SQLite → HF Dataset)
```

## 🔐 الأمان أولًا (اقرأ قبل أي شيء)

- **لا تضع أي رمز (token) داخل أي ملف أو خلية.** كل السكربتات تقرأ الرمز من
  البيئة: في Colab عبر **Secrets** (أيقونة المفتاح، اسم `HF_TOKEN`، مع تفعيل
  Notebook access)، ومحليًا عبر `hf auth login`.
- استخدم **رمزًا جديدًا**: رمز *Read* للتنزيل، ورمز *Write* مؤقت فقط إذا رفعت
  النموذج للـ Hub — **وألغه فورًا بعد الرفع** من huggingface.co/settings/tokens.
- إذا سبق أن لصقت رمزًا في ملف أو دردشة، **ألغه الآن** واعتبره مكشوفًا.
- النسخ المستخرجة من الـ bucket تُعامل كبيانات غير موثوقة: الاستخراج مفحوص ضد
  عبور المسارات (`../`) والـ Zip Bomb، و**لا سكربت ينفّذ أي ملف مستخرج** —
  الملفات البرمجية في النسخ الاحتياطية تُعدّ فقط وتُتجاهل.

## الخطوات

### 1) تنزيل الـ bucket
```bash
python 1_download_bucket.py                     # المجلد 2026-10-14 افتراضيًا
python 1_download_bucket.py --prefix 2026-10-14 --dest ocr_data/bucket_downloads
```
يعرض شجرة الملفات أولًا ثم ينزّلها إلى `ocr_data/bucket_downloads/`.
إذا فشل: تأكد من تسجيل الدخول (`hf auth whoami`) ومن أن حسابك مُصرَّح به على الـ bucket.

### 2) فحص النسخ وتجهيز صفحات الوسم
```bash
python 2_inspect_backups.py
```
يستخرج الأرشيفات بأمان، يرندر PDF إلى صفحات (يحتاج `PyMuPDF`)، ينسخ الصور
المؤهلة إلى `ocr_data/pages/` بأسماء فريدة مع تصحيح دوران EXIF، ويكتب
تقرير `ocr_data/pages/inventory.json`. الصور الصغيرة (أيقونات الواجهات) تُستبعد
تلقائيًا (`--min-kb 50 --min-px 200`)، وما تبقى قد يحوي صورًا ليست صفحات خط —
تجاهلها داخل أداة الوسم.

### 3) قص ووسم الكلمات (Gradio + SQLite)
```bash
python 3_labeling_app.py
```
داخل Colab يفتح رابطًا عامًا تلقائيًا. لكل صفحة:
1. انقر **زاوية الكلمة العلوية** ثم **الزاوية السفلية المقابلة** (صندوق أحمر).
2. اكتب نص الكلمة كما هي بخط اليد.
3. «💾 حفظ القصاصة» — تُقص من الصورة الأصلية (بالإحداثيات الأصلية) وتُحفظ
   في `ocr_data/crops/` مع صف في SQLite (`crops.db`).
4. «✅ إنهاء الصفحة» تنقلك للتالية غير المكتملة.

إضافات: تراجع عن آخر قصاصة، إدخال إحداثيات يدوي احتياطي، وتحويل النقر تلقائيًا
من صورة العرض إلى الصورة الأصلية. **عند الانتهاء أوقف الخلية (Stop) وانتقل للخطوة 3ب.**

### 3ب) مراجعة الوسوم الآلية (قبل التصدير)
```bash
python 3b_review_app.py
```
الوسوم المستوردة من قاعدة بيانات مشروعك حالة `auto` (OCR أولي بثقة متفاوتة) —
هذه الأداة تجعل المراجعة أسرع من الوسم من الصفر:
- تُعرض القصاصات **الأقل ثقة أولًا** (الأرجح خطأً) مع الوسم الآلي جاهزًا للتعديل.
- ✅ **قبول** (verified=1، يمر للتصدير دومًا)، 💾 **تصحيح النص**، 🚫 **تجاهل**
  (قصاصة غير مقروءة — تُستبعد من التصدير)، ⏭️ **تخطي**، ↩️ **تراجع**.
- فلتر باللغة (عربي/إنجليزي/ألماني) وترتيب بالثقة أو بالأحدث.

### 3ج) مراجعة وتعديل مربعات الكلمات على الصفحات
```bash
python 7_box_editor_server.py            # ثم افتح http://127.0.0.1:7863
python 7_box_editor_server.py --port 9000
```
التقسيم الآلي قد يقطع الكلمة أو يضمّ أكثر من كلمة — هذه الواجهة تعرض كل صفحة
**كاملة**، أو **سطرًا**، أو **جزءًا مكبّرًا** من السطر مع مربعات الكلمات فوق الصورة:
- انقر مربعًا و**اسحب حوافه/زواياه** لتوسيعه أو تضييقه (أو حرّكه من داخله)،
  وأزرار `أوسع/أضيق/يمين/يسار ±` للضبط الدقيق بالبكسل.
- **انقر أي فراغ فوق كلمة بلا مربع → يتشكّل المربع تلقائيًا حول حبرها**:
  الخادم يقسّم شريط السطر بفجوات الأعمدة الحبرية (البروفيل العمودي) فيأخذ
  **الكلمة المنقورة فقط** — بلا جيرانها ولو لامسا — مع نقطها وشُدّتها،
  **ملاصقًا لحبرها تمامًا بلا أي فراغ أبيض** (نمط حفظ الـpatterns في
  ABBYY FineReader)، ويتحمل النقر داخل ثقب حرف أو في الفجوة بين كلمتين.
- **⤡ ضيّق** يقلّص المربع المحدد و**ضيّق الكل** يقلّص مربعات الصفحة كلها إلى
  حدود الحبر تمامًا مع **إعادة قص القصاصات فورًا** — فتكون أبعاد بيانات
  التدريب ثابتة ومتسقة؛ ما هو ملاصق أصلًا لا يُعدّل، والمنطقة الخوية من
  الحبر تُتخطى، وكل تقليص يُسجَّل في سجلي التدقيق والنشاط.
- **✨ تحليل** يكشف كل كلمات الصفحة ويضيف مربعات مبدئية ضيقة حولها (يتخطى
  الموجود تلقائيًا)، ويكشف **فاصل الأعمدة** في صفحات العمودين — من عناقيد
  أسطر القاعدة أو الممر العمودي — فيُرسم بخط أحمر متقطع، وزر «الفاصل»
  يظهره/يخفيه، وكتل حبر خارج الأسطر (مجموعات زوايا الصفحة) تُكتشف أيضًا.
- **⬇ TXT / ⬇ DOCX** تصدّر نص الصفحة بترتيب القراءة: **المجموعة العلوية
  أولًا** (حتى مجموعات زوايا الصفحة وأعلاها) ثم الكتل الأعلى فالأعلى،
  وبداخل السطر من اليمين لليسار للعربية. وأضف `&order=columns` لجعل
  العمود الأيمن كاملًا أولًا. يشمل التصدير الكلمات الموسومة غير المتجاهلة.
- **سجل النشاط** `ocr_data/app_log.jsonl` يسجل كل ما يجري في البرنامج
  (بدون صور أو نصوص) ويُقرأ من `/api/log`؛ وإرسال بيانات الاستخدام المجهولة
  إلى المطوّر لا يتم إلا بعد **إذن المستخدم** عند أول تشغيل — من الطرفية أو
  نافذة الواجهة، ويُغيَّر بـ `--consent yes|no`.
- **الأسهم** تحرّك المربع المحدد (مع Shift أسرع)، و**Ctrl+الأسهم** تغيّر حجمه:
  يمين/يسار للعرض وأعلى/أسفل للطول، و`[ ]` توسيع/تضييق ±5px من الجانبين.
- **✂ تقسيم** مربع يضم كلمتين إلى مربعين، **دمج مع الجار** لكلمة مقسومة على
  مربعين، **➕ مربع جديد** لكلمة لم يلتقطها الاكتشاف التلقائي، **تجاهل** للشظايا.
- تصحيح الوسم واللغة مباشرة، و`Enter` يؤكد الوسم وينتقل للكلمة التالية في السطر.
- ثلاثة ألوان: أزرق = آلي، أخضر = مؤكد بشريًا، رمادي متقطع = متجاهل.
- **الحفظ تلقائي** في `crops.db` بعد كل تعديل، مع سجل تدقيق
  `ocr_data/box_adjustments.jsonl`، و**إعادة قص تلقائية** لصورة القصاصة بالحدود
  الجديدة من صفحة الصفحة الأصلية. بعد المراجعة أعد تشغيل الخطوة 4 (التصدير).

### 4) تصدير مجموعة البيانات
```bash
python 4_export_dataset.py
```
ينظف الوسوم الآلية (علامات الاتجاه المخفية، التطويل، الشظايا غير المقروءة مثل
`et`/`_`، مع تطبيع NFC لعلامات الترميم الألمانية ö/ü/ä/ß)، يستبعد المتجاهلة
`ignored`، **يمرّ كل وسم مُراجَع بشريًا `verified=1` ولو كان قصيرًا** (ja, im, zu…)،
يوزع الصفحات على `train/val/test` **على مستوى الصفحة** (كل قصاصات الصفحة في
تقسيم واحد — يمنع تسريب نمط الخط والحبر)، ويحفظ `ocr_data/hf_dataset`
(أعمدة: `image, text, page, language`) ونسخة تدقيق CSV تشمل اللغة.
خيارات مفيدة: `--min-confidence 0.6` (وسوم أعلى ثقة فقط) و`--no-clean`
(تعطيل التنظيف الآلي).

### 5) التدريب على Colab T4
```bash
python 5_train_trocr_colab.py --epochs 20
```
- **المسار الثلاثي اللغات (الافتراضي):** معمارية TrOCR — ترميز `ViT` + فك
  `bert-base-multilingual-cased` بطبقات cross-attention. لماذا؟ مفردات
  `microsoft/trocr-*` **لاتينية فقط ولا تستطيع توليد حرف عربي واحد**، ومفردات
  AraBERT لا تحتوي علامات الترميم الألمانية ö/ü/ä/ß (تسقط إلى `[UNK]`) —
  بينما مفردات mBERT تغطي العربية والألمانية والإنجليزية معًا. لعربي بحت:
  `--decoder aubmindlab/bert-base-arabertv2`.
- **المسار اللاتيني:** `--latin` يضبط `microsoft/trocr-small-handwritten` مباشرة.
- عند نفاد الذاكرة (OOM): `--batch-size 4` و/أو `--image-size 224`.
- المقاييس: CER/WER على تقسيم val مع حفظ أفضل نموذج وتوقف مبكر (صبر 4 حقبات).
- رفع اختياري: `--push-repo USERNAME/name` — يقرأ `HF_TOKEN` من البيئة فقط.

### 6) تجربة النموذج
```bash
python 6_predict.py --model trocr-multilingual-handwritten --image ocr_data/pages
python 6_predict.py --model trocr-multilingual-handwritten --image ocr_data/crops --max 20
```

## ⚖️ توقعات واقعية

| حجم القصاصات الموسومة | ما تتوقعه |
|---|---|
| < 200 | نموذج تجريبي — يتدرب لكن نتائجه متواضعة |
| 500–2000 | دقة معقولة على كلماتك نفسها بأسلوبك |
| 3000+ | أساس جيد لتعميم محتمل على خطوط مشابهة |

نصائح ترفع الجودة بلا مجهود كبير: وسم صفحات أكثر وليس قصاصات أكثر من نفس
الصفحة؛ وثّق الصفحات بإضاءة متشابهة؛ اترك بعض الصفحات للاختبار ولا تدرب عليها.
